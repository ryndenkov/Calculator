🧮 Калькулятор на Jetpack Compose

Приложение калькулятора для Android, полностью написанное на Kotlin с использованием Jetpack Compose

Этот учебный проект демонстрирует чистую архитектуру, реактивный UI и управление состоянием

✨ Возможности

Современный UI в стиле Material Design - Полностью реализован на Jetpack Compose

Полнофункциональный калькулятор:

Базовые арифметические операции (+, -, ×, ÷)

Функции очистки и удаления

Поддержка десятичных дробей

Вычисление результата

🏗️ Архитектура

Приложение использует паттерн Model-View-ViewModel (MVVM):

UI-слой: Компоненты Jetpack Compose

ViewModel: Управляет состоянием UI и бизнес-логикой

Управление состоянием: Использует mutableStateOf для реактивных обновлений
